盤前報價與暫定換倉

早上只看門檻；交易前輸入幣安最新價格才得到盤前代理確認。此訊號不等同美股正式開盤確認。

1. 目前已知的條件

請使用 MSTR、MSTU 的股票／ETF 報價，不可使用 MSTUUSDT 永續合約的價格冒充。

2. 計算結果

尚未輸入盤前報價。你可以先看左側門檻與預先判斷的情況。

這裡只記錄策略訊號持倉，並不計算實際股數、現金與報酬；請另到「實際資產追蹤」登記每筆成交。

3. 正式開盤價補記（不是再次下單）

可於美股正式開盤後輸入美股市場的正式 MSTR/MSTU 開盤價，讓工具比較盤前與正式訊號是否不同。這裡不會改寫你已經成交的交易，也不會把幣安報價混進官方歷史均線。

資料完整性與拆股提醒

日線的開盤、收盤價格須來自美股同一個歷史調整口徑，不可拿幣安盤前價格直接補成正式美股價格。

目前內附資料以先前上傳的前復權日線為基礎。如果發生 MSTR／MSTU 拆股、反分割或歷史價格重新調整，請停止輸入並匯入整份重新調整的歷史資料，否則均線可能失真。

交易紀錄與跨裝置備份

沒有 Supabase 連線時，資料會存放於本機；登入並同步後可跨裝置保存。此處仍可手動匯出備份。

跨裝置帶走資料

你在 Windows 保存的日線和持倉，不能自動出現在 iPhone。先按「匯出備份」，放進 iCloud Drive／AirDrop，再於另一台裝置匯入；匯入會覆蓋該裝置目前的本機紀錄，請先備份。

請不要在共享電腦公開匯出含真實交易資訊的備份。網站不會要求你的交易所 API Key、密碼或助記詞。

架設成手機可開啟的網頁

這個 index.html 是單檔離線網站；可以先在 Windows／Mac 雙擊直接開啟。若要在 iPhone Safari 使用，建議將它發布至自己管理的 GitHub Pages／Cloudflare Pages 靜態網站。

公開靜態網站只會公開內附的歷史研究資料和前端程式，不會自動上傳你個人的持倉與交易紀錄。因為沒有後端帳戶功能，不提供跨裝置自動同步。

iPhone 的「檔案」直接預覽 HTML 可能不會正常保存網頁資料，因此優先使用 HTTPS 網址。

同步行為與安全提醒

登入後，正式行情更新、原工具交易紀錄與實盤帳務，會各自嘗試自動同步。其他裝置重新開啟頁面即可取得雲端資料；已開啟的裝置可按「重新讀取雲端資料」。同時在兩台裝置編輯同一份資料時，會停止覆寫並提示衝突，避免默默把其中一台的紀錄蓋掉。

Supabase 無法登入、網路中斷時仍可本機操作，但「已存本機」不代表「已成功同步雲端」。請在換裝置前檢查同步狀態，並定期另外備份。這是手動研究工具，不直接連接幣安帳戶。
